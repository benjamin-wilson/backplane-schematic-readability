# KiCad schematic work

For any KiCad schematic creation, meaningful edit, or handoff, automatically read and follow `{{SKILL_PATH}}` before authoring. This applies to new Backplane projects without another user reminder.

Draw coherent locally wired circuits, not isolated labeled component stubs. Use labels for net names, shared rails and distant or cross-sheet connections. Include functional grouping, useful explanatory notes, and meaningful title blocks. Run the shared readability checker at saved milestones, resolve actionable findings, and visually inspect the rendered sheets. Running a checker alone does not qualify an unreadable drawing.

Preserve project scope and electrical connectivity during presentation changes; coordinate one CAD writer and use supported Konnect/native editing tools. Do not infer permission for PCB placement or routing. Explicit user/project requirements take precedence.

Neatness is required: use aligned symbols and short, consistently spaced orthogonal wires, minimize crossings and repeated jogs, keep wires away from text and symbol bodies, and make junctions unambiguous. Rearrange schematic symbols to simplify the drawing while preserving pin-to-net connectivity. Reject tangled or unnecessarily meandering wiring during visual review even if automated checks are clear. This does not authorize PCB placement or routing.
